# 牧场视频证据台

智慧牧场比赛视频的素材审阅、内容理解与成片规划页面。仓库把分散的视频素材整理为关键帧、场景摘要、事件时间线和语音讲解记录，帮助课题组快速检索、复核并确定剪辑顺序。

## 快速访问

### [打开在线展示页面](https://loveisnottheeverything.github.io/cattle-video-review/)

页面由 GitHub Pages 托管，无需登录或安装软件，可通过电脑、平板和手机的现代浏览器直接访问。如果更新后仍看到旧版本，请使用 `Ctrl + F5` 强制刷新。

## 页面能做什么

- 按场景、主体、动作、标签、讲解内容或原始文件名搜索素材。
- 按理解状态和时长筛选、排序，支持三帧网格与紧凑列表视图。
- 在详情中查看关键帧、内容摘要、主体说明和事件时间线。
- 查看语音理解补充、设备部件说明与可辨语音记录。
- 连续预览超短元件素材，判断其是否适合作为零件特写。
- 切换浅色或深色主题，并在不同尺寸设备上自适应显示。

搜索框支持原始文件名和路径关键词，但公开页面不会把文件名或具体存放位置渲染在卡片、详情或图片说明中。

## 公开页面与本地页面

| 内容 | GitHub 公开页面 | 课题组本地页面 |
| --- | --- | --- |
| 文件名和具体路径 | 不显示；仅作为页面内搜索索引 | 完整保留并显示 |
| 理解模型名称 | 不显示 | 保留，便于内部追溯 |
| 关键帧 | 提供，按完整画面适配显示 | 提供 |
| 原始视频 | 不公开原始视频集合；仅包含派生的超短素材预览 | 可按本地路径播放 |
| API 密钥与生成环境 | 不包含 | 仅保存在本地环境中 |

公开仓库只包含静态展示页、派生关键帧和超短素材预览，不包含原始视频集合、API 密钥、生成脚本、完整分析工作目录或模型身份信息。为保证按原始文件名搜索，公开页面内部索引仍保留相应检索词，但不会在界面中展示。

## 与比赛成片的关系

本仓库不是最终比赛视频，而是成片制作前的“素材证据台”。当前成片计划如下：

| 段落 | 建议时长 | 目标内容 | 当前素材状态 |
| --- | ---: | --- | --- |
| 背景与意义 | 约 10 秒 | 项目问题、应用价值与比赛主题 | 文案和代表画面待最终确定 |
| 产品设计 | 20 至 30 秒 | 产品设计图、概念图、三维图、零件与功能 | 实物素材已有，设计图后续补充 |
| 核心原理 | 约 20 秒 | 理论原理、论文图示与测量逻辑 | 论文图和动画后续补充 |
| 实物部署 | 约 20 秒 | 整体、局部特写和现场讲解 | 已有较完整现场素材 |
| 实际应用 | 约 30 秒 | 牛只通过、实时点云、提示灯、分群门开关和后台数据 | 主要现场素材已有，后台图后续补充 |
| 研发团队 | 约 10 秒 | 团队合影与工作照 | 图片后续补充 |

后续剪辑应基于页面中的事件时间线定位素材，并在剪辑清单中持续记录“成片时间段、素材序号、原始文件名、本段用途”。原始文件名只在本地工作流程中使用。

## 仓库结构

```text
.
├── index.html
├── README.md
└── video_review_assets/
    ├── short_components_sequence.mp4
    └── thumbs/
```

- `index.html`：公开展示页，包含结构化理解数据和全部交互逻辑。
- `video_review_assets/thumbs/`：公开页面使用的派生关键帧。
- `short_components_sequence.mp4`：超短元件素材的连续预览。
- `README.md`：仓库定位、访问方式、数据边界和维护流程。

## 在个人设备上本地预览

在线页面无法访问时，可以克隆仓库并启动本地静态服务器：

```powershell
git clone https://github.com/loveisnottheeverything/cattle-video-review.git
cd cattle-video-review
python -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000/>。停止服务可在终端按 `Ctrl + C`。

## 维护者更新与发布

页面由上一级本地工作目录中的生成脚本统一导出：

```powershell
python build_video_review_page.py --export-site
```

导出完成后，在本仓库中检查并发布变更：

```powershell
git status --short
git add README.md index.html video_review_assets
git commit -m "Update video review site"
git push origin main
```

推送到 `main` 后，GitHub Pages 会自动构建。发布完成后应至少检查：

1. 在线首页和代表性关键帧是否返回正常。
2. 文件名搜索是否能够命中对应素材。
3. 公开卡片与详情是否隐藏路径和模型名称。
4. 手机和桌面端的图片是否完整显示。
5. 仓库中是否意外出现原始视频、密钥或本地工作文件。

## 内容说明

页面中的视频理解结果用于素材整理和剪辑决策，不应视为对现场事实的最终认定。标记为“待人工复核”的内容需要结合原视频确认；重要的人物身份、设备功能和比赛表述也应由项目成员最终审核。

如需反馈页面问题、补充素材或申请复用内容，请通过仓库的 [Issues](https://github.com/loveisnottheeverything/cattle-video-review/issues) 与维护者沟通。

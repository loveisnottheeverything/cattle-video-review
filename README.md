# 牧场视频证据台

智慧牧场比赛视频的素材审阅、内容理解与成片规划页面。仓库把现场视频整理为关键帧、场景摘要、事件时间线和语音讲解记录，帮助课题组与比赛评审快速理解产品、查看阶段样片并定位关键素材。

## 快速访问

### [打开在线展示页面](https://loveisnottheeverything.github.io/cattle-video-review/)

页面由 GitHub Pages 托管，无需登录或安装软件，可通过电脑、平板和手机的现代浏览器直接访问。如果更新后仍看到旧版本，请使用 `Ctrl + F5` 强制刷新。

## 优先查看基础样片

在线页面在素材库之前醒目展示当前比赛基础样片。样片用于对齐叙事结构、时长和素材缺口，不是最终参赛成片；当前导出没有音轨，设计图、原理图、后台界面、旁白配乐和团队素材补充后仍会持续更新。

也可以直接下载仓库中的 [比赛基础样片](video_review_assets/competition_draft.mp4)。

## 页面能做什么

- 直接播放比赛基础样片和 5 条关键现场视频。
- 按场景、主体、动作、标签、讲解内容或原始文件名搜索素材。
- 按时长排序，支持三帧网格与紧凑列表视图。
- 在详情中查看关键帧、内容摘要、主体说明和事件时间线。
- 查看语音理解补充、设备部件说明与可辨语音记录。
- 切换浅色或深色主题，并在不同尺寸设备上自适应显示。

搜索框支持原始文件名和路径关键词，但公开页面不会把文件名或具体存放位置渲染在卡片、详情或图片说明中。

## 公开页面与本地页面

| 内容 | GitHub 公开页面 | 课题组本地页面 |
| --- | --- | --- |
| 文件名和具体路径 | 界面不显示，仅作为搜索索引 | 完整保留并显示 |
| 理解模型名称 | 不显示 | 保留，便于内部追溯 |
| 视频 | 1 个基础样片与 5 条关键素材的网页压缩副本 | 可按本地路径播放原片及全部工作素材 |
| 关键帧 | 492 张，仅对应 164 条有效素材 | 保留完整工作资料，包括未公开条目 |
| 超短与待复核内容 | 不包含数据、视频或关键帧 | 本地工作资料仍保留，便于后续人工处理 |
| API 密钥与生成环境 | 不包含 | 仅保存在本地环境中 |

公开仓库不包含原始视频全集、API 密钥、生成脚本、完整分析工作目录或模型身份信息。公开视频使用匿名素材编号和网页压缩副本，不改变本地原始文件。

## 与比赛成片的关系

本仓库不是最终比赛视频，而是成片制作前的“素材证据台”。当前成片计划如下：

| 段落 | 建议时长 | 目标内容 | 当前素材状态 |
| --- | ---: | --- | --- |
| 背景与意义 | 约 10 秒 | 项目问题、应用价值与比赛主题 | **基本可满足**：牧场环境、牛群和通道画面充足；项目名称、权威数据来源与最终旁白仍需定稿 |
| 产品设计 | 20 至 30 秒 | 产品设计图、概念图、三维图、零件与功能 | **不满足**：只有实物和局部结构画面，缺概念图、总装图、三维图及零件功能对应图 |
| 核心原理 | 约 20 秒 | 理论原理、论文图示与测量逻辑 | **不满足**：屏幕画面只能作占位，缺论文原图、算法流程和可公开实验数据 |
| 实物部署 | 约 20 秒 | 整体、局部特写和现场讲解 | **可满足**：设备整体、部件特写与现场讲解较完整；李院长身份已确认 |
| 实际应用 | 约 30 秒 | 牛只通过、实时点云、提示灯、分群门开关和后台数据 | **部分满足**：真实过牛素材充分，但缺点云旋转、完整门开关与后台数据库的连续证据 |
| 研发团队 | 约 10 秒 | 团队合影与工作照 | **基本可满足**：已有工作镜头和多组合影；成员姓名、角色、单位与署名顺序仍需确认 |

当前基础样片已经按六段结构完成约 115 秒的画面级拼接，尚未加入旁白、配乐或现场同期声。其中产品设计和核心原理段仍是实物或系统界面的占位画面。实际应用段来自多个时间不同的素材，只能说明设备部署和运行片段，不能表述为同一头牛完成“点云旋转、提示灯、分群门开关、数据库记录”的连续闭环验证。

## 仓库结构

```text
.
├── index.html
├── README.md
└── video_review_assets/
    ├── competition_draft.mp4
    ├── videos/
    │   ├── material_128.mp4
    │   ├── material_154.mp4
    │   ├── material_164.mp4
    │   ├── material_169.mp4
    │   └── material_170.mp4

```

- `index.html`：公开展示页，包含结构化理解数据和交互逻辑。
- `competition_draft.mp4`：当前比赛基础样片的网页压缩副本。
- `videos/`：5 条关键素材的匿名网页压缩副本。
- `thumbs/`：164 条有效素材的派生关键帧。

## 在个人设备上本地预览

```powershell
git clone https://github.com/loveisnottheeverything/cattle-video-review.git
cd cattle-video-review
python -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000/>。停止服务可在终端按 `Ctrl + C`。

## 维护者更新与发布

页面由上一级本地工作目录中的生成脚本统一导出：

```powershell
python build_video_review_page.py --export-site
```

导出完成后，在本仓库检查并发布变更：

```powershell
git status --short
git add README.md index.html video_review_assets
git commit -m "Update video review site"
git push origin main
```

发布前应确认公开数据中只有 164 条有效素材、5 个关键视频和 1 个基础样片，并检查页面是否隐藏文件路径与模型名称。

## 内容说明

页面中的视频理解结果用于素材整理和剪辑决策，不应视为对现场事实的最终认定。重要的人物身份、设备功能和比赛表述应由项目成员最终审核。

如需反馈页面问题、补充素材或申请复用内容，请通过仓库的 [Issues](https://github.com/loveisnottheeverything/cattle-video-review/issues) 与维护者沟通。
